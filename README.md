# ¿Por qué lo hago? · Miedo o amor

Votación anónima para la noche de hogar de instituto (basada en "¿Cómo sé si mis acciones coinciden con mi porqué?", YA Weekly, nov. 2026).

- `index.html`: página para votar desde el celular (se abre con el QR).
- `termometro.html`: pantalla para proyectar, con QR y termómetro de resultados en vivo.
- Las situaciones se editan en `config.js`.
- Para una ronda nueva, agrega `?ronda=nombre` al link del termómetro.
